Lite Cron - 轻量级定时任务调度器

仓库地址 https://github.com/pdone/lite-cron

简介

平时总有些脚本需要定时运行，比如签到、数据备份、定时推送等。传统做法要么用系统自带的 cron，要么部署一套像 Airflow 这样的重型调度平台，配置繁琐不说，管理起来也麻烦。

lite-cron 就是一个为解决这类痛点而生的轻量级定时任务调度器，基于 Docker 部署，环境隔离、迁移方便。内置 Flask Web 管理界面，浏览器即可查看任务状态和执行日志；自带通知系统，任务失败自动推送；更贴心的是内置了多个常用的签到脚本，克隆下来改个配置就能跑。

功能特性

  • 基于 Docker 部署，一键启动，环境隔离
  • 使用 Cron 表达式配置定时规则，灵活简单
  • 内置 Flask Web 管理界面，支持移动端访问
  • 支持 Webhook / NTFY 通知，任务结果实时推送
  • 自动记录执行日志，方便排查问题
  • 环境变量管理敏感配置，安全可控
  • 内置多个签到脚本，开箱即用

字段 说明 示例

Web 管理界面

lite-cron 内置了基于 Flask 的 Web 管理界面，可以直观地查看任务状态和执行日志，并且做了移动端适配。

WebUI 默认只绑定 127.0.0.1，外部网络无法访问。如需公网访问，必须同时满足以下条件，否则会拒绝启动：

  1. 设置高强度访问令牌 WEBUI_TOKEN
  2. 设置 WEBUI_HOST=0.0.0.0
  3. 前置反向代理提供 HTTPS 与访问控制

⚠️ 若设置了 WEBUI_HOST=0.0.0.0 但未配置 WEBUI_TOKEN，WebUI 会拒绝启动，防止未授权访问。
